# IAAM — учёт инвестиций

## Что система умеет сейчас

IAAM принимает факты двумя независимыми путями:

- брокерский отчёт — через `POST /v1/ingest/csv` и загрузку документа
  `POST /v1/documents`; строки разбираются отдельно и получают собственный
  вердикт;
- операции из API — через `POST /v1/ingest/operations`. Внутри приложения
  есть отдельные клиенты и разбор ответов API брокера; общий код разбора с
  отчётным каналом не используется, чтобы ошибка одного канала не
  маскировала ошибку другого.

Журнал остаётся источником истины, а сверка строится заново по интервалу и
измерению: `cash`, `positions`, `income` и `tax_basis`. Для измерения
система различает `provisional`, `accepted_internal`,
`accepted_independent` и `discrepant`. Независимое подтверждение возможно,
например, когда API брокера подтверждает разобранный отчёт; два отчёта,
разобранные тем же парсером, независимым каналом не становятся.

Отчёт `GET /v1/reports/returns` возвращает доходность **до налога**,
стоимость контура, применённые правила и блок `data_quality`. В нём есть
доли стоимости по четырём статусам и материальные проблемы. Периметр §11
сохраняет наблюдаемый денежный эффект, но не выдумывает экономику для
маржи, РЕПО, шортов и других неподдерживаемых случаев; такой случай может
сделать отчёт за затронутый счёт невычислимым, не отменяя остальные счета.

## Чего система пока не умеет

Публичный маршрут `POST /v1/brokers/{broker}/sync` запускает синхронизацию
одного счёта за переданный интервал и возвращает построчный итог. Если ключ
или доступ брокера не настроены, маршрут отвечает `503`, а не `501`.
Периодического планировщика пока нет.
Маршруты `GET|POST|DELETE /v1/classification-rules` подключены: правила
хранят историю версий, а добавление и удаление запускают пересчёт этой
истории. Эти маршруты больше не являются заглушками `501`.

Система не считает налоги, не получает рыночные цены самостоятельно, не
считает TWR, NAV-ряд или доходность за произвольный подинтервал, не
поддерживает шорты, маржу и производные как экономику портфеля, не
восстанавливает потерянный ключ шифрования из одной базы и не имеет
веб-интерфейса. Цену и курсы для расчёта должны предоставить входные
данные или владелец. Периодический планировщик синхронизации,
депозитарный отчёт и справка налогового агента отложены.

Порядок дальнейших работ — в `.internal/specs`.

## Запуск

См. `docs/deployment.md`. Описание API для внешнего агента —
`docs/agent-skill/SKILL.md`, машиночитаемая спека — `/v1/openapi.json`

## Разработка

Все команды выполняются внутри `nix develop`.

- Тулчейн: `rustc 1.98.0 (88d9e12ae 2026-08-18)` (`cargo 1.98.0 (797e8a9bc 2026-08-05)`)
- Редакция: 2024

```bash
nix develop            # войти в окружение
cargo test --workspace
```

С `direnv` (файл `.envrc` в корне) окружение подхватывается при входе в
каталог, и префикс `nix develop -c` не нужен.

## Заслоны качества

Каждый заслон проверен падением на намеренно внесённом нарушении.
Настроенный, но непроверенный заслон хуже отсутствующего — он создаёт
ложную уверенность. Три из них при такой проверке оказались fail-open
и были переписаны.

| Заслон | Команда | Что ловит |
|---|---|---|
| Формат | `cargo fmt --all -- --check` | расхождение стиля |
| Линты | `cargo clippy --workspace --all-targets --all-features -- -D warnings` | деградацию качества |
| Запрет `unsafe` | компилятор, через `[workspace.lints.rust]` | `unsafe` в крейтах первой стороны |
| Архитектура | `./scripts/check-architecture.sh` | направление зависимостей, `f64` и `async` в ядре, крейту без `[lints] workspace = true` |
| Diff-lint | `./scripts/check-diff-lint.sh <база>` | новые `allow`/`expect`/`ignore`/`todo!` и правку файлов политики |
| Фикстуры | `./scripts/check-fixtures.sh` | правку замороженного эталона и мёртвые фикстуры |
| Зависимости | `cargo deny check` | уязвимости, лицензии, неизвестные источники |
| Тесты | `cargo nextest run --workspace --all-features` | регрессии |
| Покрытие по диффу | `diff-cover lcov.info --fail-under=90` | непокрытый новый код |
| Мутации | `./scripts/check-mutants.sh` | тесты, проходящие впустую (порог по каждому модулю) |

**Заслон не чинится ослаблением.** Если он мешает — либо код неверен, либо
заслон требует осознанного исключения, вносимого отдельным коммитом
с обоснованием.

### Изменение файлов политики

`check-diff-lint.sh` помечает правки в `scripts/`, `.github/workflows/`,
`deny.toml`, `clippy.toml`, `.cargo/mutants.toml`, `Cargo.toml`,
`tests/fixtures/`, `flake.nix`, `flake.lock` и `rustfmt.toml`. Такие
изменения проходят CI только с переменной `POLICY_CHANGE_APPROVED=1`,
которую выставляет владелец репозитория, а не агент.
