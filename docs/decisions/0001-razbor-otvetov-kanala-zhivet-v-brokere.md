# 0001. Разбор ответов брокерского API живёт в `iaam-broker`

Дата: 2026-08-25 · Статус: принято · Бид: iaam-w07

## Что решаем

Порт `BrokerChannel` в `iaam-app/src/ports.rs` объявлен возвращающим
`Vec<SubmittedOperation>` и `Vec<ControlClaim>`. Первый тип живёт
в `iaam-ingest`, а заслон архитектуры запрещает `iaam-broker` зависеть
от соседних адаптеров, включая ingest. План задачи 18 при этом велит
разбирать ответы API в `crates/iaam-broker/src/tinkoff.rs`. Где-то
из этих трёх утверждений надо уступить.

## Решение

Разбор ответов остаётся в `iaam-broker`. Он даёт **собственный** тип
канала (`ChannelOperation`) и ядровый `ControlClaim` для портфеля.
Реализация порта `BrokerChannel` живёт в `iaam-app/src/adapters/`
и переводит `ChannelOperation` в `SubmittedOperation` механически.

## Почему

Разбор чужого протокола принадлежит адаптеру этого протокола. Вынести
его в приложение значило бы протащить формы ответов T-Invest в слой
сценариев и сделать `iaam-app` вторым адаптером — при том, что заслон
запрещает даже транспорту знать адаптеры.

Независимость каналов (§10.3) от этого не страдает. Она держится
не на разных конечных типах, а на том, что `ChannelOperation` строится
отдельным кодом разбора, не пересекающимся с парсером XLSX: общая
ошибка не может исказить обе стороны сверки одинаково. Общий доменный
тип на выходе — не общий источник ошибки.

## Граница, по которой проверяется решение

В адаптере приложения допустима только склейка: подстановка счёта,
происхождения, версии разбора и сборка `SubmittedOperation`. **Если там
приходится трактовать знаки, статусы, виды операций, валюты или
округление — логика ошибочно вытекла из `iaam-broker`, и это признак
нарушения, а не повод расширить адаптер.**

## Следствия

- У канала API и у парсера отчёта разные версии разбора, разные
  образцы и разный код отображения; общими остаются только устойчивые
  типы ядра.
- Тест `tinkoff_mapping.rs` проверяет `ChannelOperation` и
  `ControlClaim`; тривиальное получение `SubmittedOperation`
  проверяется отдельным тестом адаптера.
- План задачи 18 в этом месте неточен и читается через это решение.

Совет по решению запрошен у стороннего ревьюера (Codex) и совпал
с принятым вариантом.
