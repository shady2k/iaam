# PRA-001 — A change to the broker sync path merges on green CI without a live sync on its build

Status: active
Since: 2026-11-14
Evidence: PR #16 broke every T-Invest sync after a green CI (iaam-xzz5.4.13); PR #20 (iaam-xzz5.5.3) merged on green CI before its live check; feature iaam-xzz5.

## Class

A change to the broker sync path is merged on green CI alone, and the first
live sync after the merge is where it breaks.

## Mechanism

CI is green because the tests answer with invented broker responses. Live
answers carry shapes and limits no fixture had — rate limits, report
pagination, unusual operation kinds — so green CI looks like enough when it
has not exercised what fails.

## Practice

Before merging anything that touches the sync path (the gateway, broker
clients and adapters, the sync scenario, ingest of broker operations), run one
live full-history sync of every connected account on the branch's build, on a
checkpointed instance, and read the outbound log: requests per method, 429
answers, pauses and verdicts. Merge only on that and green CI, and record the
live run in a note on the task.

Where the live allowance is short, a recorded-answer replay (iaam-xzz5.6, once
built) may stand in for the live run.

## How we will know

No sync-path pull request is merged without a live-run note on its task, and
the next retrospective finds no post-merge sync regression.
