# PRA-003 — A commit puts in parentheses an item it does not deliver

Status: active
Since: 2026-11-14
Evidence: commits f7d0a708 (names iaam-dvki while filing an epic) and 8a888745 (names iaam-s7ue2 while raising a budget) — two features. The backlog gate's merged-but-open list shows both as landed though neither was delivered, and main's history cannot be changed.

## Class

A commit message names in parentheses an item the commit does not deliver, and
the backlog reads it as delivered.

## Mechanism

The project's commit-link convention reads only ids inside parentheses as
"this commit delivers it" (`docs/backlog-integration.md`, Commit task links).
Writing a related item in parentheses looks like ordinary citation.

## Practice

In a commit message, parentheses hold only the items the commit delivers. Any
other item is mentioned bare: "see iaam-x", "filed iaam-y".

## How we will know

The merged-but-open list shows no new item whose work is not on main.
